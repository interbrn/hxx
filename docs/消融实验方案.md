# 消融实验方案

## 目的

消融实验只回答“跨分辨率融合模块是否带来增益，以及增益来自哪一部分”，不改变数据划分、检测类别、测试流程或任务定义。研究对象始终是 `fire` 和 `person` 目标检测，不是图像融合或超分辨率。

## 统一条件

- 数据集：RGBT-3M。
- RGB：480×640；2∶1 条件下 IR：240×320。
- 按视频分组使用 `train_grouped.txt`、`val_grouped.txt`、`test_grouped.txt`。
- YOLOv8n 双流检测器，seed=0，AdamW，初始学习率 0.001，nbs=64，100 epoch，余弦学习率，nonmosaic 增强。
- 训练完成后只用验证集最优 `best.pt` 在独立 test 集评价。
- 记录 Precision、Recall、mAP50、mAP50-95；同时记录参数量和 FLOPs。

## 消融矩阵

| 编号 | 条件 | 保留模块 | 去除模块 | 目的 |
|---|---|---|---|---|
| A0 | 2∶1 直接拼接 | 双流、特征对齐、concat | 适配器、门控 | 跨分辨率基线 |
| A1 | 2∶1 + adapter | A0 + 多感受野适配 | 门控 | 测试特征适配贡献 |
| A2 | 2∶1 + adapter + channel gate | A1 + 通道门控 | 空间门控 | 区分通道权重作用 |
| A3 | 2∶1 + adapter + channel + spatial gate | A2 + 空间门控 | — | 测试完整门控组合 |
| A4 | A3 + auxiliary loss | A3 + RGB/IR 辅助检测头损失 | — | 测试辅助监督贡献 |
| A5 | A3 - auxiliary loss | A3 主检测损失 | 辅助损失 | 与 A4 配对比较 |

当前代码和历史 smoke 已实际覆盖 A0、A1、A3、固定等权对照以及 A5 的流程级验证。A2、A4 和完整数据的 A0–A5 仍属于服务器正式实验，不应由 smoke 指标替代。

## 判读规则

1. 只在同一数据划分、同一 epoch、同一 seed、同一训练参数和同一 test 流程下比较。
2. 先比较 mAP50-95，再结合 mAP50、Recall、Precision 判断是否稳定改善。
3. 若加入模块后只提升 Recall 而 Precision 明显下降，应记录为检测工作点变化，不能直接写成“性能全面提升”。
4. smoke 结果只证明代码链路和输出流程可运行；论文结论使用完整数据、100 epoch 结果。
