# 正式训练前检查清单

## 1. 数据和任务

- 数据集为 RGBT-3M。
- RGB 和 IR 按文件名一一配对。
- 检测类别为 `fire` 和 `person`。
- 使用视频分组的 train、val、test 文件。
- 2∶1 实验保持 RGB 为 480×640，IR 为 240×320。
- test 集只用于训练结束后的最终评估。

## 2. 不得用于论文结果的配置

以下配置只用于调试代码和检查模型：

- `configs/rgbt3m_debug4.yaml`
- `configs/rgbt3m_overfit_same4.yaml`
- `splits/debug_train_4.txt`
- `splits/debug_val_4.txt`

## 3. 两种运行 profile

| profile | 数据 | epoch | batch | 设备 | 用途 |
|---|---|---:|---:|---|---|
| `local_cpu` | smoke 分组 | 2 | 1 | CPU | 本地流程验证 |
| `server_full` | 完整分组 | 100 | 默认 16 | GPU | 正式实验 |

运行入口为 `train.py`。实验模式通过 `--experiment` 选择，包含 `rgb`、`ir`、`ratio1_concat`、`ratio2_concat`、`ratio2_simple`、`ratio2_adapter` 和 `ratio2_gated`。

服务器需要连续运行全部模式时，使用：

```text
python tools/run_experiments.py --profile server_full --data-root <DATASET_ROOT> --experiments all --device 0
```

正式启动前先添加 `--dry-run` 检查命令。

## 4. 训练参数

主实验建议使用：

- AdamW；
- 初始学习率 0.001；
- `nbs=64`；
- 3 epoch warmup；
- 余弦学习率；
- nonmosaic 增强；
- 固定 seed=0；
- 主实验关闭辅助损失。

本地 smoke 使用 `nbs=1`、1 epoch warmup 和无增强，不得把 smoke 参数直接当作正式参数。

完整参数见 `configs/experiment_protocol.yaml`。

## 5. 输出和缓存

每个训练目录应包含：

- `weights/best.pt`
- `weights/last.pt`
- `results.csv`
- `results.png`
- `test_metrics.json`
- `experiment_manifest.json`

缓存和临时文件统一写入项目目录：

- `.dataset_cache/`
- `.yolo_config/`
- `.matplotlib/`
- `.pytest_tmp/`

这些目录已加入 `.gitignore`，不会上传 GitHub。

## 6. 结果检查

- 检查训练损失是否出现 NaN。
- 检查 RGB 和 IR 特征尺寸是否正确对齐。
- 检查 `best.pt` 是否来自验证集最佳结果。
- 检查 test 指标是否来自独立 test 集。
- 检查所有对比实验是否使用相同数据划分和训练参数。
- smoke 结果只能说明流程跑通，不能作为论文最终结论。
