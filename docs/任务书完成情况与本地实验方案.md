# 面向火情目标检测的可见光—红外跨分辨率特征融合方法研究

## 1. 项目目标

本项目研究 RGB 和红外图像的跨分辨率特征融合，用于 `fire` 和 `person` 目标检测。项目不做图像融合，也不做超分辨率重建。

实验规定如下：

- RGB 输入保持 480×640。
- 1∶1 实验中 IR 输入为 480×640。
- 2∶1 实验中 IR 输入为 240×320。
- 模型基于 YOLOv8n 双流检测结构。
- 训练、验证和测试使用固定的视频分组，避免相邻视频帧泄漏。
- 最终指标使用独立 test 集计算。
- 本地 CPU 只用于流程验证，正式实验计划使用完整数据和 100 epoch GPU 训练。

## 3. 实验矩阵

| 编号 | 实验 | 配置模式 | 目的 |
|---|---|---|---|
| A | RGB 单模态 | `rgb` | RGB 基线 |
| B | IR 单模态 | `ir` | IR 基线 |
| C | 1∶1 双流直接拼接 | `ratio1_concat` | 同分辨率双流基线 |
| D | 2∶1 双流直接拼接 | `ratio2_concat` | 跨分辨率直接拼接基线 |
| E | 2∶1 固定等权融合 | `ratio2_simple` | 对比固定融合权重 |
| F | 2∶1 特征适配 | `ratio2_adapter` | 验证多感受野适配作用 |
| G | 2∶1 通道和空间门控 | `ratio2_gated` | 验证可学习 RGB/IR 权重 |

`ratio1_gated` 和 `hierafire` 是额外扩展模式，不替代任务书中的 A 至 G。

## 5. 统一运行参数

训练入口支持两个 profile：

| 参数 | `local_cpu` | `server_full` |
|---|---:|---:|
| 数据 | smoke 分组 | 完整分组 |
| epoch | 2 | 100 |
| batch | 1 | 默认 16，按显存调整 |
| nbs | 1 | 64 |
| 设备 | CPU | GPU 0 |
| 优化器 | AdamW | AdamW |
| 初始学习率 | 0.001 | 0.001 |
| warmup | 1 epoch | 3 epoch |
| 学习率 | 普通衰减 | 余弦衰减 |
| 增强 | none | nonmosaic |
| 辅助损失 | 关闭 | 主实验关闭，另做消融 |
| seed | 0 | 0 |

完整参数见 `configs/experiment_protocol.yaml`。每次训练结束后，运行目录保存 `experiment_manifest.json`。

## 7. 结果解释规则

- smoke 结果只能证明流程和代码能够运行。
- 不同 epoch 的结果不能直接比较。
- 不同数据划分、增强、batch 或随机种子的结果不能直接比较。
- 论文主表应使用完整分组数据、统一 100 epoch 和独立 test 集。
- mAP50、mAP50-95、Recall 和 Precision 需要结合观察，不能只看单个指标。
- 没有功耗实测时，不得声称模型节能。
