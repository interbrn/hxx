# RGBT-3M 实验运行指南

本项目提供两个运行 profile：

| profile | 数据 | 设备 | 默认 epoch | 用途 |
|---|---|---|---:|---|
| `local_cpu` | micro 视频分组 | CPU | 2 | 本地流程验证 |
| `server_full` | 完整视频分组 | CUDA | 100 | 正式实验 |

本地可以通过 `--epochs 5` 进行较长 smoke 验证，但该结果仍不能替代正式实验。

## 1. 数据目录

数据集根目录应包含：

```text
RGBT-3M/
├── RGB/
├── IR/
└── labels_fire_person/
```

RGB、IR 和标签应使用相同的相对文件名。数据集路径通过 `--data-root` 传入，不写入配置文件。

## 2. 安装环境

先按照 PyTorch 官方安装说明安装与设备匹配的 PyTorch 和 torchvision，再安装其余依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-cpu.txt
```

服务器环境应先按照 CUDA 版本安装匹配的 PyTorch 和 torchvision，再执行 `python -m pip install -r requirements.txt`。项目直接使用仓库内的 `ultralytics/`，不需要安装同名外部包。

## 3. 运行前检查

```powershell
python tools/validate_project.py `
  --data-root D:\path\to\RGBT-3M `
  --profile local_cpu `
  --experiments core
```

检查工具不会训练模型，主要验证目录、类别、划分文件、代表性样本、RGB/IR 尺寸和配置完整性。

## 4. 本地 CPU 版本

```powershell
python tools/run_experiments.py `
  --profile local_cpu `
  --data-root D:\path\to\RGBT-3M `
  --experiments core `
  --epochs 5 `
  --run-tag local_cpu_5epoch `
  --dry-run
```

确认命令后删除 `--dry-run` 以启动训练。若只验证一个实验：

```powershell
python train.py `
  --profile local_cpu `
  --experiment ratio2_gated `
  --data-root D:\path\to\RGBT-3M `
  --epochs 5
```

## 5. 服务器完整数据版本

```bash
python tools/validate_project.py \
  --data-root /data/RGBT-3M \
  --profile server_full \
  --experiments core

python tools/run_experiments.py \
  --profile server_full \
  --data-root /data/RGBT-3M \
  --experiments core \
  --device 0 \
  --dry-run
```

确认无误后执行正式实验：

```bash
python tools/run_experiments.py \
  --profile server_full \
  --data-root /data/RGBT-3M \
  --experiments core \
  --device 0 \
  --run-tag server_full_100epoch
```

`server_full` 默认使用完整视频分组、100 epoch、AdamW、`nbs=64`、余弦学习率和 nonmosaic 增强。

## 6. 扩展实验

`--experiments all` 会额外运行 `ratio1_gated` 和 `hierafire`。扩展实验不应与核心矩阵混合解释，应单独记录模型结构、参数量、训练参数和测试指标。

## 7. 断点续训和结果保护

批量入口执行前会检查目标目录：

1. 存在有效 `test_metrics.json` 时跳过训练；
2. 只有 `last.pt` 时自动续训；
3. 只有 `best.pt` 时保留目录，不自动覆盖；
4. 使用 `--force` 才允许重新训练。

每个完整运行目录应包含：

```text
weights/best.pt
weights/last.pt
results.csv
results.png
test_metrics.json
experiment_manifest.json
```

## 8. 独立测试和审计

训练结束后，`train.py` 会自动使用验证集选择的最佳权重在 test 集上评估。已有权重可以单独测试：

```bash
python tools/test_checkpoint.py \
  --weights runs/detect/<RUN_NAME>/weights/best.pt \
  --data configs/rgbt3m_ratio2_grouped.yaml \
  --data-root /data/RGBT-3M \
  --device 0 \
  --name <RUN_NAME>_test
```

运行族完成后使用：

```bash
python tools/audit_run_tag.py \
  --run-tag server_full_100epoch \
  --output docs/server_full_100epoch_audit.md
```

审计内容包括必需产物、公共划分、视频组隔离、manifest 和独立 test 指标。

## 9. 结果解释

CPU micro 和短 epoch 结果只用于验证流程，不用于论文最终结论。论文主表必须来自完整视频分组、统一 100 epoch、相同训练参数和相同独立 test 流程。
