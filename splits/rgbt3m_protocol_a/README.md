# RGBT-3M 协议 A 的内部验证划分

从官方 `train.txt` 的 7,854 对中划出 **6,574 对训练、1,200 对内部验证、80 对隔离**。内部验证按官方训练池中各视频的图像对数分配名额，八条视频各取一个连续时段。在每个验证时段的前后，各从官方训练清单里留出紧邻的 5 对作为隔离。排除隔离段后，训练和内部验证的比例为 **84.56% / 15.44%**。

选择时段时，在各视频内兼顾火焰、人员、无目标帧和火焰框尺寸，在总体上尽量接近官方训练池的类别与场景来源分布。火焰框尺寸用各视频火焰框面积的中位数参照平衡采样。`video4` 和 `video5` 在官方训练池中合计仅有 3 个人员框，全部保留在训练集。
